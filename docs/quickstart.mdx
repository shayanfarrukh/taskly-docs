Create your first task, then mark it complete, in about five minutes.

## Before you begin

You need:

- A Taskly **test API key** (test keys start with `tk_test_`). See [Authentication](/authentication).
- cURL, or Python 3.9 or later with the `requests` library (`pip install requests`).

Store your key in an environment variable so it never appears in your code:

```bash
export TASKLY_API_KEY="tk_test_your_key_here"
```

## Step 1: Create a task

<Tabs groupId="language">
<TabItem value="curl" label="cURL" default>

```bash
curl -X POST https://api.taskly.example/v1/tasks \
  -H "Authorization: Bearer $TASKLY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"title": "Write quickstart guide", "due_date": "2026-12-01"}'
```

</TabItem>
<TabItem value="python" label="Python">

```python
import os
import requests

response = requests.post(
    "https://api.taskly.example/v1/tasks",
    headers={"Authorization": f"Bearer {os.environ['TASKLY_API_KEY']}"},
    json={"title": "Write quickstart guide", "due_date": "2026-12-01"},
    timeout=10,
)
response.raise_for_status()
print(response.json())
```

</TabItem>
</Tabs>

A successful request returns `201 Created` with the new task:

```json
{
  "id": "tsk_8f2a1c",
  "title": "Write quickstart guide",
  "status": "open",
  "due_date": "2026-12-01",
  "created_at": "2026-11-07T09:30:00Z"
}
```

Copy the `id` value. You need it in the next step.

## Step 2: Mark the task complete

<Tabs groupId="language">
<TabItem value="curl" label="cURL" default>

```bash
curl -X POST https://api.taskly.example/v1/tasks/tsk_8f2a1c/complete \
  -H "Authorization: Bearer $TASKLY_API_KEY"
```

</TabItem>
<TabItem value="python" label="Python">

```python
response = requests.post(
    "https://api.taskly.example/v1/tasks/tsk_8f2a1c/complete",
    headers={"Authorization": f"Bearer {os.environ['TASKLY_API_KEY']}"},
    timeout=10,
)
response.raise_for_status()
print(response.json()["status"])  # completed
```

</TabItem>
</Tabs>

The response is the updated task with `"status": "completed"`.

## Step 3: List your tasks

<Tabs groupId="language">
<TabItem value="curl" label="cURL" default>

```bash
curl "https://api.taskly.example/v1/tasks?status=completed&limit=10" \
  -H "Authorization: Bearer $TASKLY_API_KEY"
```

</TabItem>
<TabItem value="python" label="Python">

```python
response = requests.get(
    "https://api.taskly.example/v1/tasks",
    headers={"Authorization": f"Bearer {os.environ['TASKLY_API_KEY']}"},
    params={"status": "completed", "limit": 10},
    timeout=10,
)
response.raise_for_status()
for task in response.json()["data"]:
    print(task["id"], task["title"])
```

</TabItem>
</Tabs>

## Pagination

List endpoints return up to `limit` items and a `next_cursor` value. To fetch the next page, pass that value as the `cursor` parameter. When `next_cursor` is `null`, you have reached the last page.

```python
cursor = None
while True:
    params = {"limit": 100}
    if cursor:
        params["cursor"] = cursor
    page = requests.get(
        "https://api.taskly.example/v1/tasks",
        headers={"Authorization": f"Bearer {os.environ['TASKLY_API_KEY']}"},
        params=params,
        timeout=10,
    ).json()
    for task in page["data"]:
        print(task["id"])
    cursor = page["next_cursor"]
    if cursor is None:
        break
```
