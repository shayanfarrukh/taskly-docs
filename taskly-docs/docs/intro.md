The Taskly API lets you create tasks, mark them complete, and receive webhook events when tasks change.

## API at a glance

- **Base URL:** `https://api.taskly.example/v1`
- **Format:** JSON requests and responses
- **Authentication:** Bearer API key
- **Pagination:** cursor-based
- **Specification:** OpenAPI 3.1 ([view the source file](https://github.com/shayanfarrukh/taskly-docs/blob/main/openapi/openapi.yaml))
